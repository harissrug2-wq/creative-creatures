CRM Connector guide

Connect an authorized CRM location to Creative Creatures for live contacts, opportunities, pipelines, and assigned-user context.

Connect

  1. Sign in to Creative Creatures.
  2. Open Integrations and find CRM Connector.
  3. Select Connect, choose the location you are authorized to manage, and approve the requested access.
  4. After returning to Creative Creatures, select Sync now.

Use the connection

Select Manage to review live contacts, opportunities, and pipelines. Changes made there are written to the connected CRM location.

Disconnect

Open Integrations and select Disconnect beside CRM Connector. This removes the agency's saved connection and stops future synchronization.

Data access

The connector requests only location metadata, contacts, opportunities, pipelines, and user information needed for the integration. Each connection is isolated to its corresponding Creative Creatures agency.
