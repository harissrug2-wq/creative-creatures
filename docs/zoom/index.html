Zoom for Creative Creatures

Connect one Zoom user to an agency workspace and manage that user's upcoming meetings without leaving Creative Creatures.

What the integration does

  • Loads the connected Zoom user's identity and upcoming meetings.
  • Creates scheduled meetings.
  • Updates meeting topic, time, duration, timezone, agenda, waiting-room, and join-before-host settings.
  • Deletes meetings only after the user confirms the action.
Access boundary

This is a user-managed connection. It accesses only data authorized for the Zoom user who connects it. It does not provide account-wide Zoom administration.

Connect Zoom

  1. Sign in to the correct Creative Creatures agency workspace.
  2. Open Integrations and find Zoom.
  3. Select Connect, sign in to Zoom, review the requested permissions, and choose Allow.
  4. After returning to Creative Creatures, Zoom should show Connected. Select Manage to load meetings.

Manage meetings

Select Manage beside Zoom. The meeting manager shows the connected host and upcoming meetings. Use New Meeting to create a meeting. Select Edit to retrieve the current saved values from Zoom before changing them. Select Delete and confirm to remove a meeting.

Permissions

Creative Creatures requests the minimum user-level permissions needed to read the connected user's profile, list and read meetings, and create, update, or delete meetings at the user's direction.

Data not requested

The integration does not request or process Zoom recordings, transcripts, meeting chat, attendance reports, camera data, microphone data, webinar data, phone data, or contacts.

Disconnect Zoom

  1. Open Integrations.
  2. Find Zoom and select Disconnect.
  3. Confirm the action. Creative Creatures attempts to revoke the token and deletes its stored Zoom connection record.

Troubleshooting

If Zoom authorization fails, confirm the app is available to your Zoom account and retry using the correct Zoom user. If meetings are missing, confirm they are owned by the connected user and are upcoming meetings. For help, contact creature@creativecreatures.org.
