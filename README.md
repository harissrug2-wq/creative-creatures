# Creative Creatures Combined

One Vite project containing four pages:

- `/diagnostic/` — Agency Diagnostic hub
- `/agency-scorecard/` — Agency Scorecard
- `/independence-index/` — Owner Independence Index
- `/agency-strength-index/` — Agency Strength Index

## Local development

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
```

Deploy the repository root to Vercel with the Vite preset. No separate projects or environment variables are required for the current front-end-only build.
